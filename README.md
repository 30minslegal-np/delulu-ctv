# delulu-ctv
Cộng tác viên dịch thuật Công ty cổ phần DELULU
## Lưu ý
- Trang không có backend, không tự lưu hợp đồng hay dữ liệu CTV lên server.
- Thư viện docx.js được tải từ jsDelivr CDN nên xuất Word cần kết nối Internet.
- Tỷ lệ % được nhập riêng mỗi lần tạo hợp đồng. Chưa có cơ sở dữ liệu quản lý CTV.
- Dữ liệu cá nhân không được đưa vào mã nguồn/repository công khai.
